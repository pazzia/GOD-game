# APK для тестирования

**[AlmostGod-0.5.1-preview.apk](AlmostGod-0.5.1-preview.apk)** — текущая сборка, отдельный файл без архива.

Откройте APK и нажмите **Download raw** (значок загрузки справа). Если чат не запускает скачивание, откройте страницу в браузере телефона.

Размер:163651486байт (164МБ). Android10+, ARM64. На телефоне: **«Почти бог · UX тест»**. Устанавливается рядом с прежней игрой; удалять старую версию не нужно. Новое прохождение отдельное, автоматического переноса нет.
