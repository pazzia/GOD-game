# APK для тестирования

**[AlmostGod-0.5.0-preview.apk](AlmostGod-0.5.0-preview.apk)** — отдельный файл, без архива.

Откройте файл и нажмите **Download raw** (значок загрузки справа).
Если чат не запускает скачивание, откройте страницу в браузере телефона.

Размер: 163 631 006 байт (164 МБ). Android 10+, ARM64.
Проверенный APK хранится в Git LFS; контрольная сумма — в [SHA256SUMS.txt](SHA256SUMS.txt).

[Резервная страница скачивания в Releases](https://github.com/pazzia/GOD-game/releases/tag/android-preview-40277464897-1).
