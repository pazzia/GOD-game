# Почти бог / Almost God

Головоломка о профессоре Феликсе и Плюме: подготовьте опыт, покажите невозможный результат, запишите закон в Атлас и примените его. 30 уровней, русский и английский языки, горизонтальный полноэкранный режим Android.

**Тестовая версия 0.5.1-preview, build 7.** Исправления по результатам прогона роли «Игрок».

## Скачать APK

**[Открыть отдельный APK 0.5.1 в GitHub](https://github.com/pazzia/GOD-game/blob/main/artifacts/android/AlmostGod-0.5.1-preview.apk)** → нажмите **Download raw** (значок загрузки). Это обычный `.apk` без архива; файл хранится в Git LFS. Размер: 163 651 486 байт, Android 10+, ARM64.

[Резервная страница Releases](https://github.com/pazzia/GOD-game/releases/tag/android-preview-0.5.1-ux2).

На телефоне новая игра называется **«Почти бог · UX тест»**. Она устанавливается рядом с прежней версией, без её удаления. Прохождение и настройки новой установки отдельные. Это изолированная тестовая сборка с уникальным App ID; она не обновляет старую подпись и не переносит старые сохранения. Старую игру и её данные оставьте на месте.

## Что изменилось

- Следующий шаг учитывает выбранный и уже размещённый реквизит; остановка плана называет препятствие.
- Подсказки относятся к текущему этапу, отдельно до и после записи закона.
- План показывает реальные маршруты, крепления, опоры и состояние выполнения.
- Размещение отделено от осмотра: неподходящее место объясняется без переключения предмета; метки видны перед реквизитом.
- Пауза, главное меню и доступность доступны без прокрутки звуковых каналов. Сохраняется выбранный раздел настроек.
- Исправлены номер уровня при крупном тексте, контраст и диагностика обзора. Осмотр наблюдателей не включает перемещение; обзор Марфы доступен через её тело.

[Проверка и ограничения](docs/reviews/ux-fixes-0.5.1/README.md), [первый независимый проход новой версии](docs/reviews/ux-fixes-0.5.1/player-review.md), [сведения об APK](docs/production/ux-fixes-0.5.1/delivery.json).

## Проверки

GitHub Actions выполнил **33 обязательных набора**, проверил подпись, фактический App ID, namespace провайдеров и состав APK: [успешная сборка](https://github.com/pazzia/GOD-game/actions/runs/40316007540). Скачанные байты независимо сверены по SHA-256, manifest и игровым ресурсам.

Новый AI-Игрок естественно прошёл L01–L03, проверил паузу, 140% и продолжение. Независимый QA повторил ошибку доставки, её объяснение и исправление. Два оставшихся замечания к обозначению/перекрытию мишеней размещения сохранены в [журнале](docs/reviews/ux-fixes-0.5.1/player-findings.md). Это desktop-проверка мышью; физический Android, человеческое понимание и субъективное прослушивание ещё не проверены. Кадры до финальной коррекции наблюдателей и кадры окончательного кода различены по runtime digest.

## Запуск исходников

Нужен **Godot 4.7.2 stable**, стандартная версия без .NET. Импортируйте `project.godot` и запустите `main.tscn`:

```bash
godot --editor --path .
godot --path .
```

Закреплённые инструменты хранятся вне Git; Linux setup требует Python, JDK17 и сети:

```bash
python3 tools/bootstrap_native.py --tools-dir ../GOD-native-tools
python3 tools/verify_project.py --godot ../GOD-native-tools/Godot_v4.7.2-stable_linux.x86_64 --ui --audio
```

Для проверки PNG нужен Pillow, аудио — FFmpeg; повторная генерация музыки также использует NumPy. Готовые ресурсы включены в проект.

## Сборка и поставка

[Android workflow](.github/workflows/android-preview.yml) собирает изменения main и теги `android-preview-*`: импорт → все тесты → экспорт → фактические проверки APK → отдельный asset в Releases. Исходники, настройки и выбранные APK хранятся в Git; APK в `artifacts/android/` использует LFS. При ручном клонировании с отключённым LFS-smudge скачайте APK через `git lfs pull` или кнопку Download raw.

Для CI-review используется App ID `com.almostgod.game.review.r<RUN_ID>.a<ATTEMPT>`. Каждый запуск изолирован, потому что исторический CI-ключ не сохранялся. Постоянный обновляемый канал требует отдельной защищённой настройки ключа; [план и ограничения перехода](docs/reviews/android-signing/2026-10-26-report.md). Private keys, пароли и SDK не входят в Git, LFS, Releases или исходный ZIP. Публикация в магазине не выполнялась.
