# Почти бог / Almost God

Мобильная головоломка о фокуснике Феликсе и его помощнике Плюме: скрой механизм, покажи свидетелям невозможное, закрепи чудо печатью и используй новый закон. Кампания включает 30 уровней и 46 эталонных прохождений; поддерживаются русский и английский языки.

**Версия 0.4.0-preview, Android build 5** переработана по отзыву после испытания 0.3.0: горизонтальная ориентация, полноэкранный Android, крупная сцена, объёмно стилизованные окружения, новая типографика и музыка. Это 2D-игра с оформлением в духе 3D-мультфильма; исходные персонажи используют 2D-риги.

Игра явно разделяет подготовку фокуса, убеждение зрителей и применение нового закона. Принятое доказательство ещё не означает победу: текущая цель и следующие действия видны в боковой панели. Все три зрителя доступны одновременно; касание показывает их состояние. После выполнения обязательных условий открывается следующий уровень.

Музыкальная партитура полностью заменена: семь новых спокойных композиций, 15 фоновых файлов и пять коротких акцентов. MIDI, генератор, происхождение инструментов и лицензии включены в проект. Предметные эффекты, голоса и атмосферы сохранены.

Подробности: [состояние проекта](docs/PROJECT_STATE.md), [решения после отзыва](docs/decisions/2026-10-25-landscape-preview.md), [дизайн и UX](docs/design/landscape-ux.md), [музыка](docs/audio-rework.md), [облачная среда](docs/cloud-environment.md). Исторические отчёты 0.2/0.3 относятся к прежним сборкам.

31 набор проверок пройден; скачанный APK проверен по SHA-256, ZIP CRC и совпадению ресурсов с исходниками. Сведения о поставке — [docs/reviews/ci/android-preview.json](docs/reviews/ci/android-preview.json).

Workflow [Android preview APK](.github/workflows/android-preview.yml) собирает APK на GitHub из точного коммита тега `android-preview-*`. Для нового теста создайте и отправьте новый тег на нужном коммите; также доступен ручной запуск workflow после его включения в основную ветку.

Сборка устанавливает закреплённый Godot 4.7.2, выполняет полный прогон с UI и аудио, проверяет подпись APK, состав ресурсов и совпадение отпечатков исходников. Только успешный результат публикуется в [GitHub Releases](https://github.com/pazzia/GOD-game/releases): APK, отчёт сборки, результаты проверок, сведения об исходном коммите и SHA-256. Журналы доступны в Actions. Исходники и настройки сборки хранятся в Git; APK хранится в Releases.

APK рассчитан на Android 10+ / ARM64. Каждый запуск CI создаёт временный тестовый ключ вне репозитория. Для замены ранее установленной сборки `com.almostgod.game.preview` может потребоваться её удаление, что удалит локальные сохранения. Закрытый ключ не публикуется. Это тестовая поставка; установка и проверка на физическом телефоне выполняются отдельно.

## Запуск исходников

Нужен **Godot 4.7.2 stable, стандартная версия**, без .NET. Импортируйте `project.godot`, дождитесь загрузки ресурсов и запустите `main.tscn` клавишей F5. Команды выполняются из корня проекта:

```bash
godot --editor --path .
godot --path .
```

Для Linux подготовлены инструменты с закреплёнными версиями и проверкой хешей. Нужны Python 3.10+, JDK 17+ и `dpkg-deb`; загрузка требует сети. Движок и SDK хранятся вне проекта:

```bash
python3 tools/bootstrap_native.py --tools-dir ../GOD-native-tools
```

## Как играть

Выберите предмет в ленте реквизита и нажмите на подсвеченное место сцены. Повторное нажатие на предмет или кнопка «Действия» открывает размещение, крепления, включение и удаление. Для точного размещения есть список именованных мест; длинные ленты и списки прокручиваются.

Карточка зрителя показывает его обзор: результат должен быть виден, секрет — скрыт. «Показать чудо» запускает проверку; после принятия свидетелями нажмите «Закрепить чудо». Через «План» назначаются маршруты и следующий фокус. «Разыграть план» запускает движение Феликса и грузов по выбранным путям.

Планирование без таймера, репетиция, откат и три последовательные подсказки бесплатны. В настройках доступны RU/EN, крупный текст, уменьшение движения, субтитры, вибрация и раздельная громкость музыки, эффектов, окружения, голосов и интерфейса. Настройки и прохождение сохраняются. Кампания тестовой версии доступна без покупки; магазинные платежи не подключены.

## Проверки

Для проверки графики нужен Pillow, для измерений аудио — FFmpeg; повторный синтез аудио также использует NumPy. Готовые ресурсы включены в проект.

```bash
godot --headless --editor --path . --import --quit
python3 tools/verify_project.py --godot /absolute/path/to/godot --ui --audio
```

Проверка изолирует сохранения, проверяет детерминированные прохождения, интерфейс, ресурсы, анимации, сохранения и звук. Ошибки движка и утечки учитываются даже при нулевом коде выхода процесса. Итог записывается в `tests/reports/project-verification.json`; отпечаток runtime-файлов и отсутствие их изменений во время прогона связывают результат с проверенным кодом. Старый зелёный отчёт не подтверждает изменённые исходники.

Отдельные полезные проверки:

```bash
godot --headless --path . --script tests/test_campaign.gd
godot --headless --path . --script tests/test_character_acting.gd -- --actual-rigs
python3 -m unittest discover -s tests -p test_verification_tools.py -v
python3 tools/verify_audio.py
```

## Android preview

Тестовая сборка предназначена для **Android 10+ (API 29), ARM64**. Она использует отдельный пакет `com.almostgod.game.preview` и не обновляет историческую установку `com.almostgod.game`. Минимальная версия Android приведена к ТЗ; target API — 36.

```bash
python3 tools/build_android.py --tools-dir ../GOD-native-tools --new-debug-identity --output build/AlmostGod-0.4.0-preview.apk
```

Для этой версии используйте именно `tools/build_android.py`: он создаёт временную копию официального встроенного шаблона и адресно меняет `minSdkVersion` с 24 на 29 в двоичном manifest. Исходный шаблон и остальные файлы внутри него проверяются на неизменность. Поле `gradle_build/min_sdk` оставлено пустым, поскольку встроенный экспорт Godot не принимает эту Gradle-настройку. Прямой экспорт из редактора не гарантирует минимум Android 10; фактический manifest готового APK проверяет сборщик.

Результат — APK и соседний `AlmostGod-0.4.0-preview.build.json` с SHA-256, фактическими параметрами manifest, сертификатом и отпечатком исходников. Сборщик проверяет подпись и manifest готового APK. Он создаёт постоянный локальный тестовый ключ в `../GOD-local-signing/preview-debug.keystore`; сохраните этот файл отдельно для следующих обновлений preview. Ключ не входит в Git или ZIP исходников и не подходит для магазинного выпуска.

Без `--new-debug-identity` сборщик требует утраченный исторический ключ и завершится ошибкой, если его нет. Новая подпись не выдаётся за восстановление прежней. На физическом Android и iOS версия ещё не принята; iOS требует macOS/Xcode и отдельной подписи.

Известное ограничение preview: при заполнении диска сервис сохранений возвращает ошибку; предусмотрена резервная копия, но интерфейс пока не сообщает игроку о неудачной записи. Надёжность поведения при нехватке места требует доработки перед выпуском.

## Архив исходников и просмотр сцен

```bash
python3 tools/package_project.py --output ../Almost-God-0.4.0-preview-source.zip
godot --path . res://tools/level_workbench.tscn
godot --path . res://tools/puppet_viewer.tscn
python3 tools/capture_ui.py --tools-dir ../GOD-native-tools --output build/native-review --quick
```

Архиватор проверяет CRC и заменяет готовый ZIP атомарно. Включены графические и музыкальные исходники, полное ТЗ, командные навыки, тесты и отчёты; исключены SDK, импорт-кэш, сборки и локальные ключи. Историческая папка `old/` сохранена в Git и по умолчанию не дублируется в ZIP; для её включения есть `--include-old`. Снимки сцен выполняются настоящим Godot/Mesa/Xvfb, а не макетом интерфейса.

## Структура проекта

| Путь | Назначение |
|---|---|
| `core/` | Детерминированные правила, команды и проверка данных |
| `presentation/` | Сенсорный интерфейс, сцена и анимация |
| `services/` | Сохранения и аудиомикшер |
| `data/levels/`, `data/localization/` | 30 уровней и 616 ключей RU/EN |
| `data/character_animations.json` | 47 дополнительных клипов персонажей |
| `assets/art/`, `assets/art/source/` | Runtime-графика, исходники, промпты и происхождение новых изображений |
| `assets/audio/production/`, `assets/source/audio/` | 222 звука, MIDI и сведения о синтезе |
| `tests/`, `tools/` | Проверки, авторские инструменты и сборка |
| `docs/specification-package/` | Сохранённое полное ТЗ |
| `.agents/skills/` | Навыки менеджера, архитектора, дизайнера и разработчика из архива пользователя |
| `old/` | Художественные оригиналы; исключены из runtime |

`tools/author_campaign.py`, `tools/author_localization.py` и `data/authoring/` — источники авторских данных. Генераторы перезаписывают результаты, поэтому ручные правки сначала вносятся в источник. Из JSON уровней код не выполняется. Лицензии внешних компонентов приведены в [ASSET_NOTICES](docs/ASSET_NOTICES.md).
