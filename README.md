# Почти бог / Almost God

Перенос материалов от 24 октября 2026: [состав, готовый APK и актуальные ограничения](TRANSFER.md). Это сохранение проекта в GitHub без деплоя. Свежий аудит выявил нестабильное завершение одного тестового набора; исторические успешные отчёты ниже относятся к прежним запускам.

Мобильная головоломка о сценическом фокуснике Феликсе и его помощнике Плюме. Скрой способ исполнения фокуса, убедительно покажи результат трём зрителям и закрепи невозможное печатью. После этого камни действительно плавают, огонь замораживает или бумага становится прочнее стали. Последствия нового закона — следующая часть задачи.

Текущая ветка: **0.2.0, Android build 3, испытательная версия**. Кампания содержит 30 уровней в трёх главах, три комбинируемых закона и 16 авторских альтернативных решений. Это исходный проект Godot для мобильных платформ. Статус полной художественной и платформенной приёмки находится в `docs/PROJECT_STATE.md`; наличие ресурсов и зелёных автоматических проверок само по себе не означает выпускную готовность.

Общий прогон 25 наборов пройден на замороженных файлах. Подписанный APK собран из того же набора исходников; независимая проверка пакета — 710 проверок без ошибок. Это не испытание на физическом устройстве.

## Запуск

1. Установи Godot **4.7.2 stable, стандартную версию**. .NET не требуется.
2. Импортируй `project.godot` в редактор Godot и дождись импорта ресурсов.
3. Нажми F6/F5 или запусти главную сцену `main.tscn`.

Из командной строки, находясь в этой папке:

```bash
godot --editor --path .
godot --path .
```

Приложенный отдельно Android APK предназначен для самостоятельной установки и проверки. Он подписан тестовым ключом и не является магазинным релизом. Для исходного APK используется ARM64; iOS требует отдельной сборки и подписи на macOS/Xcode. Отсутствующие устройства и аккаунты не заменяются имитацией успешной проверки.

## Как играть

Нажми на предмет в ленте реквизита, затем на подсвеченное место на сцене. Повторное нажатие на предмет или кнопка «Действия» открывает его размещение, крепления, включение или удаление. Для точного размещения доступен список именованных мест. Горизонтальная лента и длинные списки прокручиваются.

Карточка зрителя показывает его обзор: результат должен быть виден, а секрет — скрыт. «Показать чудо» запускает проверку. Когда зрители поверили, нажми «Закрепить чудо». В меню «План» назначаются маршруты и выбирается следующий фокус. «Разыграть план» даёт миру действовать; Феликс и груз перемещаются по выбранным путям. Третий закон требует явно заменить один из двух действующих законов.

Планирование не ограничено таймером. Есть бесплатные откат, репетиция и три последовательные подсказки для каждого уровня. После пройденного уровня открывается следующий. Весь звук, музыка, эффекты, голоса, окружение и звуки интерфейса регулируются отдельно и запоминаются. В настройках доступны русский/английский языки, размер текста, уменьшение движения и вибрация.

## Проверки

Требуются Python 3.10+ и указанная версия Godot. Для повторного синтеза аудио нужны NumPy и FFmpeg; готовые звуки уже включены. Для проверки изображений нужен Pillow.

```bash
godot --headless --editor --path . --import --quit
python3 tools/verify_project.py --godot /absolute/path/to/godot --ui
python3 tools/verify_project.py --godot /absolute/path/to/godot --ui --audio
```

Сводный запуск изолирует сохранения каждого набора проверок. Текущие результаты записываются в `tests/reports/` и `build/`. Запуски до изменения кода не считаются доказательством корректности изменённого кода. Итоговый отчёт содержит отпечаток исполняемых ресурсов и отмечает изменения во время проверки.

Непосредственные логические проверки:

```bash
godot --headless --path . --script tests/test_kernel.gd
godot --headless --path . --script tests/test_campaign.gd
godot --headless --path . --script tests/test_s2_regressions.gd
godot --headless --path . --script tests/test_validation.gd
```

## Состав проекта

| Папка | Назначение |
|---|---|
| `core/` | Детерминированные правила, состояния, команды и строгая проверка данных |
| `presentation/` | Сенсорный интерфейс, прорисовка сцены и визуальная интерполяция |
| `services/` | Сохранения и аудиомикшер |
| `data/levels/` | 30 описаний уровней |
| `data/localization/` | Русские и английские тексты |
| `assets/art/` | Растровая графика, векторные значки и авторские исходники |
| `assets/audio/production/` | Готовые музыка, эффекты, голоса и атмосферы |
| `assets/source/audio/` | MIDI, структура партитуры и сведения о синтезе |
| `tests/` | Эталонные решения и логические/интеграционные проверки |
| `tools/` | Авторские генераторы, валидаторы, внутренние инструменты и сборка |
| `docs/` | Полное ТЗ, архитектура, решения, ревью и открытые работы |

`tools/author_campaign.py`, `tools/author_localization.py` и `data/authoring/character_cast.json` — источники авторских данных. Повторный запуск перезаписывает сгенерированные файлы: ручные изменения сначала переноси в генератор или сохраняй отдельным авторским изменением. Никакой код не выполняется из JSON уровней.

В архив не включены движок, Android SDK/JDK, кэш импорта, приватные выпускные ключи и магазинные учётные данные. Источники иллюстраций и партитуры включены; ограничения редактируемых моделей и полноты анимации фиксируются отдельно. Сведения о внешних компонентах находятся в `docs/ASSET_NOTICES.md`.

## Android и просмотр производства

Для восстановления Linux-инструментов сборки нужен JDK 17 и `dpkg-deb`. Скрипт получает закреплённые версии и проверяет их хеши; движок и SDK не включены в исходный ZIP.

```bash
python3 tools/bootstrap_native.py
python3 tools/build_android.py --output build/AlmostGod-debug.apk
python3 tests/review_final_apk.py --apk build/AlmostGod-debug.apk
```

Сборка использует изолированную копию проекта и сохранённый тестовый сертификат. Приватная выпускная подпись и публикация магазина в этот процесс не входят. `build/AlmostGod-debug.build.json` содержит хеш APK и отпечаток исходников, который сверяется с `tests/reports/project-verification.json`.

Внутренние сцены для производства запускаются отдельно:

```bash
godot --path . res://tools/level_workbench.tscn
godot --path . res://tools/puppet_viewer.tscn
python3 tools/capture_puppets.py --actors felix plum caramelka
python3 tools/capture_ui.py
```

Снимки используют настоящий Godot/Mesa/Xvfb. Для повторного аудиоизмерения используется `tools/verify_audio.py`. Открытые художественные и аппаратные пункты перечислены в `docs/BACKLOG.md`.
