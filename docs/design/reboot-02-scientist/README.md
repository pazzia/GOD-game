# «Почти бог» — герой-учёный

Статус: **предложение на рассмотрении владельца**, 25 октября 2026.
Правка по отзыву: «молодого мальчишку надо сменить на более серьёзного дядьку учёного».

Новый кандидат — профессор Феликс, зрелый мужчина около 60 лет. Седина,
аккуратная борода, круглые очки, спокойное лицо и основательная поза подчёркивают
опыт. Тёмно-бирюзовый костюм изобретателя, записная книга и латунный полевой
прибор связывают образ с миром открытий. Сохраняются солнечный город, Плюм,
название игры и крупная кнопка входа в историю.

Текст меню согласован с профессией: «Мир невозможных открытий», «Сначала —
смелый опыт. Потом — совсем другой мир». Имя «Профессор Феликс» — рабочее.
Функция нового прибора пока не вводилась: правила Атласа и первого уровня
в reboot-01 не изменены. При утверждении образа потребуется согласовать с
геймдизайнером биографию, речь и роль учёного в истории.

Макет использует относительные ссылки на соседнюю папку `reboot-01`.
Для просмотра из корня репозитория:

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory docs/design
```

Открыть `http://127.0.0.1:8772/reboot-02-scientist/menu.html`.
Повторный экспорт: `python3 docs/design/reboot-02-scientist/export.py`.

Проверены реальные браузерные PNG на двух размерах: все три изображения и
Onest загружаются, значимый текст помещается, кнопка входа не меньше 48 px
по высоте на телефонном макете. Визуально проверены края силуэта и композиция.
У PNG сохранена мягкая полупрозрачная тёплая кайма генерации; это ещё не
нормализованный игровой спрайт. Модельные листы, игровые позы и анимации не
созданы. Код игры, APK, прежний набор макетов и публикация не изменялись.
