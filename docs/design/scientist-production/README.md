# «Почти бог» — производство нового визуала

Владелец утвердил взрослого учёного и меню, затем поручил переделать игру.
Этот набор переносит выбранное направление в отдельные ресурсы native Godot
для всех 30 существующих уровней. Исходники прежней игры не заменяются.

## Что создано

- Девять именованных участников: утверждённый профессор Феликс, Плюм и Марфа;
  новые Семён, Ника, Лада, Роза, Гуго и Карамелька. Шесть отдельных типов толпы.
- Три окружения: канал, праздничная кухонная площадь и бумажные мастерские
  у крепости. У новых площадей нижняя часть открыта для игровой композиции.
- Все 31 `PROP_*` идентификатора реквизита, встречающиеся в кампании, имеют
  новые рисованные изображения. Для очага существуют тёплое, холодное и
  выключенное состояния; для чаши — лёд, для бумаги — золотая прошивка.
  Упоры бумажного пролёта читаются как дерево, скрытый каркас — как сталь.
- Шесть опорных поверхностей: каменная площадка, деревянный причал, вода,
  лёд, бумажная площадка и каменная ступень. Они помогают сцене показывать
  настоящие authored опоры, сохраняя логику проходимости отдельно.

## Контракт интеграции

Единственный реестр — `assets/art/reboot/manifest.json`:

```text
environments[ENV01..ENV03] = {path}
characters[CH01..CH09, CROWD01..CROWD06] = {path, region?, pivot, height_ratio}
props[PROP_*, SCENE_*, ATLAS, MIRACLE_STAMP] = {path, region, pivot, variants?}
```

`path` — путь `res://`. `region` — реальные пиксели исходного PNG
`[x, y, width, height]`. Геометрия атласов не считается регулярной сеткой:
границы подобраны по фактическим изображениям. `pivot` нормализован внутри
выбранного региона; у участников он располагается между ногами, у поверхностей
определяет полезную верхнюю плоскость. `height_ratio` задаёт относительный рост.
`variants.cold` и `variants.folded` — отдельные записи с путём и регионом.

Использовать `AtlasTexture` с `filter_clip=true`. Полностью прозрачные поля
не должны растягиваться вместо тела; размер вычисляется после выбора региона.
Опоры рисуются только там, где authored геометрия уже допускает опору/берег:
новый красивый причал не создаёт проход через воду по решению рендерера.
Точные регионы и измеренные границы плотной альфы — [atlas-regions.json](atlas-regions.json).

## Источники и воспроизводимость

Пять утверждённых изображений скопированы побайтно в source и runtime;
одиннадцать новых активных PNG созданы через `image_gen.imagegen`, включая
новую квадратную иконку профессора с Плюмом. В source сохранены исходные
PNG, точные промпты и фактические reference/output paths каждого вызова.
`assets/art/source/scientist-reboot/provenance.json` содержит SHA-256 и покрытие.
Изображения не редактировались средствами Python или сторонними фильтрами.
Runtime PNG занимают 34 101 400 байт до импорта Godot; это размер файлов,
не измерение памяти GPU или Android-производительности.

Листы [asset-board.html](asset-board.html) отображают исходные PNG через те же
регионы на светлом фоне. Они предназначены для проверки ресурсов, а итоговая
художественная приёмка проводится по реальным снимкам игры.

После первого native-прогона фоны ENV02/03 пересозданы в размере 1846×852:
добавлен свободный передний пол, архитектура отодвинута. Первые отвергнутые
пластины и их точные промпты сохранены в `source/scientist-reboot/superseded/`.
Фактически свободный пол по всей ширине начинается около `y=372` для ENV02
и `y=445` для ENV03; желаемые 35–38% генератор не выдержал буквально.
Согласованная игровая проекция помещает первый ряд ступнями ниже 60% кадра,
поэтому персонажи и реквизит должны стоять на видимой поверхности. Это проверяется
повторными native-кадрами, а не обещанием из промпта.

## Статус и ограничения

Изображения интегрированы в native-сцену и приняты в пределах просмотренной
выборки: [заключительная художественная проверка](visual-review.md).
Новые второстепенные персонажи и реквизит не объявляются отдельно утверждёнными
владельцем. Все фигуры — цельные cutouts: скелетные риги, мимические листы,
развороты и сложная анимация не создавались. Допустимы аккуратные перемещения
цельной фигуры, если их честно отличать от новой актёрской анимации.

Окружения — плоские нарисованные пластины; многослойные PSD/KRA не заявляются.
Интерактивные персонажи и предметы поставлены отдельно. У некоторых исходников
есть мягкие полупрозрачные цветные отсветы вокруг силуэта; их сочетаемость
проверяется в композиции. Снимки сами по себе не доказывают понятность игры,
удобство касания на телефоне или физическую корректность игровых правил.
