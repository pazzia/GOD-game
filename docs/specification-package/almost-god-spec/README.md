# Пакет ТЗ «Почти бог», v1.0

Это исходники технического задания, таблицы и стартовые контракты. Исполняемый проект игры поставляется отдельно. Плановые ассеты и сценарии испытаний не являются выполненной реализацией.

Читайте START_CHATGPT.md для передачи задания новой сессии. Основной текст расположен в 01…07. Для единого документа используйте Almost-God-Technical-Specification.md.

- 30 проектных карточек уровней в level_blueprints.json и 03_LEVEL_DESIGN.md.
- 79 требований и 79 сценариев приёмки, связаны с 33 рабочими пакетами.
- ASSET_MANIFEST.csv: 571 требуемый ресурс со статусом planned.
- LOCALIZATION_SEED.csv: начальные RU/EN строки; непереведённые отмечены явно.
- schemas/ и examples/: контракты v1, три стартовые схемы сцены и последовательности команд.
- catalogs/: параметры правил и оригинальный нотный эскиз.
- tools/validate_spec.py: проверка документации и стартовых данных, запускается Python 3.10+ без сторонних зависимостей.
- VALIDATION_REPORT.json: результат статической проверки; не заменяет испытания в Godot.

Роли команды: ведущий агент — менеджер, отдельные дизайнер, архитектор и разработчик. Архитектор согласует контракты; дизайнер проверяет реализованный UI; менеджер принимает результаты после доказательных проверок.
