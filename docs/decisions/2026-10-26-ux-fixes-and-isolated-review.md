# Исправления UX и отдельный пакет для теста

Пользователь поручил реализовать найденные Игроком исправления и выдать новый
APK. Девять PLR-наблюдений и дополнительный дефект слоёв HUD входят в итерацию;
ранее подготовленные предложения больше не ограничены этапом аудита.

Выбрана безопасная параллельная установка этой review-сборки: уникальный
package на CI-run и attempt. Старую игру не удаляем, её локальные данные
не трогаем. Новая тестовая игра начинает отдельное прохождение.
Смена package не объявляется исправлением обновления старой подписи.
Постоянные пользовательские signing credentials в этом поручении не изменяются.

Производственный план и границы: `docs/production/ux-fixes-0.5.1/plan.md`.
