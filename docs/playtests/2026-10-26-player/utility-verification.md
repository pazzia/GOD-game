# Проверка инфраструктуры после игрового прогона

Исправлены два дефекта тестовой утилиты, а не игры: повторный `start` в
непустую папку свидетельств и завершение процесса только по потенциально
устаревшему PID. Игровой runtime не изменялся.

Защиты добавлены после завершения и остановки исходных сессий: 117 событий
Игрока и 11 событий менеджера выполнялись предыдущей версией CLI. Их 128 PNG,
журналы, manifest и остальные файлы исходных папок не изменены: повторно
сверены SHA-256 всех 136 файлов. Старые manifest не переписывались.

Новый start отказывает непустому evidence-dir до запуска Xvfb/Godot и записи
manifest. stop/restart сначала сверяют обе identity: PID, время рождения
процесса, boot ID и SHA-256 командной строки. Сигналы отправляются через
Linux pidfd; время ожидания ограничено. Неизвестная или несовпадающая
identity вызывает отказ без сигнала.

Целевые проверки: **15 PASS, 0 FAIL**. Проверены неизменность существующих
кадров/journal/manifest, отказ при отсутствующей/неверной identity, сохранение
обоих sentinel-процессов при отказе stop/restart, правильное завершение
своего процесса и ограниченная эскалация SIGKILL для процесса, игнорирующего
SIGTERM. Фактические результаты — в utility-verification.json.

Отдельный настоящий Godot smoke на display105,844×390: start → видимое меню →
XTest-click «Начать историю» → изменившийся экран → desktop SIGTERM/restart
с тем же профилем → stop. **5 сырых PNG и 5 записей журнала**, хеши и цепочка
проверены; после stop оба записанных процесса завершены, профиль сохранён.
Engine/leak-строк в логе не найдено.

При первой пробе дополнительное чтение `/proc/PID/exe` оказалось недоступно
между CLI-командами: утилита безопасно отказала. Это ограничение облачной
среды; необязательная проверка symlink удалена. Итоговый smoke выполнен
после корректировки. Это не дефект игры и не изменение прежнего прогона.

Это desktop mouse/keyboard AI-проверка с Dummy audio, не физический Android,
не touch и не субъективное прослушивание. Время запуска VM не трактуется
как производительность телефона.

[Исходные кадры и журнал отдельного smoke](utility-smoke/) скопированы
побайтно в Git; исходные пути внутри сырого журнала сохранены.
