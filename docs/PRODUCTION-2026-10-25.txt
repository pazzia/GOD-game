ANDROID
0.3.0-preview, versionCode 4, ARM64, Android 10+ (API 29), target API 36.
Отдельный пакет com.almostgod.game.preview сохраняет прежнюю установку.
Исторический signing key утрачен. Preview использует новый постоянный ключ
../GOD-local-signing/preview-debug.keystore вне Git и ZIP. Это локальная
debug-подпись, не магазинная подпись и не восстановление старого сертификата.

Сборка требует штатного tools/build_android.py. Официальный builtin-шаблон
Godot содержит minSDK 24; скрипт создаёт временную копию и меняет только
целочисленное поле minSdkVersion на 29 в binary manifest. Остальные 128
записей текущего шаблона сохраняют точное содержимое, исходный файл не меняется;
это проверяется перед экспортом. Происхождение шаблона записывается в
custom_template_provenance отчёта APK. gradle_build/min_sdk оставлено пустым,
поскольку встроенный экспорт Godot не принимает эту Gradle-настройку.
Прямой экспорт из редактора не гарантирует API 29. Фактические подпись,
версия, пакет и minSDK готового APK проверяются сборщиком.

Команды из корня проекта:
  godot --headless --editor --path . --import --quit
  python3 tools/verify_project.py --godot /absolute/path/to/godot --ui --audio
  python3 tools/build_android.py --tools-dir ../GOD-native-tools --new-debug-identity --output build/AlmostGod-0.3.0-preview.apk
  python3 tools/package_project.py --output ../Almost-God-0.3.0-preview-source.zip

ZIP включает ТЗ, навыки, авторские исходники, код, ресурсы и отчёты; исключает
SDK, кэш, сборки и ключи. old/ остаётся в Git и добавляется в ZIP только с
--include-old. Архив сначала проходит проверку CRC, затем атомарно сохраняется.

ИЗВЕСТНОЕ ОГРАНИЧЕНИЕ PREVIEW
Read-only ревью выявило: write_slot проверяет запись и операции с резервной
копией, однако UI не сообщает игроку о false при заполнении диска. Последние
изменения могут остаться несохранёнными без видимого сообщения. Исправление
индикации и проверка сценария disk full остаются работой до выпуска.

В manifest после экспорта Godot обнаружен одинаковый authority у двух
неэкспортируемых providers. Официальный шаблон до экспорта имеет разные
значения. Ошибка установки этим не доказана; проверить установку и запуск
preview на устройстве, прежде чем считать Android-приёмку завершённой.
