# UX-исправления и новая тестовая поставка 0.5.1

Основание: владелец поручил «Вноси исправления и опять дай на тест пользователю»
после первого прогона Игрока. Приёмка охватывает девять PLR-проблем из
`docs/playtests/2026-10-26-player/issues.json` и дополнительное перекрытие
диагностики обзора. Художественное направление сохраняется.

## Владение

- UI: game.gd, theme.gd, Plan/Pause/Settings, масштаб/контраст, UI-тесты.
- Guidance: quest_guide.gd, авторские данные и RU/EN, фазовые подсказки,
  короткая причина остановки, различимые складная ширма и жёсткие щиты.
- Stage: stage_view.gd, выбор и явное размещение, читаемые связи/метки,
  устранение фиксированного текста под HUD.
- Android: builder/CI/workflows/version, изолированный пакет этой сборки.
- QA/Игрок: независимые проверки изменений и нативный повторный проход.
- Менеджер: интеграция, общий import/gate, проверка доказательств, Git/LFS/APK.

Общие файлы правит один владелец; новые строковые ключи передаются Guidance.
Никаких новых художественных движков, платежей, смены правил ядра или
программного прохождения вместо проверки интерфейса.

## Контракты и приёмка

Явный режим размещения отделён от выбора/осмотра. Неподходящее место даёт
объяснение, сохраняя выбранный реквизит. План показывает фактические
назначения и связи; назначение не приравнивается к выполнению.
Подсказки и видимая причина соответствуют текущей фазе и состоянию мира.
Пауза и размер текста доступны без прокрутки звуковых каналов.
Проверяются 100/120/140%, ошибка L03, исправление плана, Undo и сохранение.

После остановки изменений: общий Godot import, все обязательные регрессии
и новый UX-набор, нативный проход, проверка RU/EN и авторских генераторов.
Затем GitHub собирает подписанный APK и проверяет manifest/состав/источники.
APK скачивается и сверяется по SHA-256, сохраняется отдельным файлом в
`artifacts/android/` через Git LFS; пользователь получает страницу файла.

## Установка этой тестовой сборки

Прежний одноразовый CI-ключ недоступен; новый ключ не восстановит обновление
старой подписи. Чтобы тест установился без удаления старой игры, используется
отдельный App ID `com.almostgod.game.review.r<RUN_ID>.a<ATTEMPT>`.
Это параллельная тестовая установка со своим прохождением, не миграция
сохранений и не постоянный обновляемый канал. Прежняя установка сохраняется.

Пользовательские ключи, GitHub Secrets и credentials не читаются и не меняются.
Создаётся только штатная одноразовая identity изолированной CI-сборки; её
private key не публикуется. Для будущего обновляемого канала остаётся план
постоянной подписи из Android-аудита. Проверка реального телефона не заменяется
проверкой различия package в manifest.
