# APK-DIRECT: отдельный файл для тестирования

26 октября 2026 владелец потребовал всегда выдавать APK без ZIP. Правило
сохранено в AGENTS.md; Android preview автоматически собирает изменения main
и публикует проверенный APK отдельным asset GitHub Releases.

Полное анонимное скачивание выполнено; сервер возвращает Android package MIME
и attachment с именем AlmostGod-0.5.0-preview.apk. Контрольные суммы APK и всех
соседних отчётов совпали с SHA256SUMS.txt. Скачанный файл повторно проверен
inspect_apk.py: 30 уровней, обязательные ресурсы соответствуют текущему runtime.
Точные URL, коммит, размер и SHA-256 — в standalone-release.json.

При повторных сборках найдено нестабильное завершение test_services.gd: после
shutdown() тест освобождал узел и выходил через 0.15 секунды, не дождавшись
освобождения native playback. Два CI-прогона корректно отклонили утечки при
нуле функциональных ошибок. Тест переведён на существующий bounded
shutdown_and_wait() с отдельным assertion; пять локальных запусков подряд
дали 27 проверок, 0 ошибок и 0 сообщений об утечках. Runtime игры не менялся.

Полная проверка рабочего проекта до этой правки теста: 32 набора PASS.
Опубликованная сборка также прошла все 32 набора и проверку подписи; её runtime
побайтно совпадает с текущим проектом. Физический телефон не испытывался.
Диагностика CI доступна отдельным tag-triggered workflow android-diagnostics.yml;
он сохраняет отчёт в отдельную ветку и не изменяет main.
