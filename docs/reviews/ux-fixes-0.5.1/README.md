# UX 0.5.1: исправления и тестовая поставка

**Готово к тесту владельца.** Реализованы изменения по девяти PLR-наблюдениям,
общий GitHub gate прошёл все **33 набора**. Новый AI-Игрок естественно прошёл
первые три уровня. После него отдельно исправлены и перепроверены переключение
наблюдателей и доступ к обзору через тело Марфы.

**[Открыть APK на GitHub](https://github.com/pazzia/GOD-game/blob/main/artifacts/android/AlmostGod-0.5.1-preview.apk)**
→ Download raw. Файл отдельный, без ZIP. Новая «Почти бог · UX тест» ставится
рядом со старой игрой, с отдельным прохождением. Старую игру удалять не нужно.

Диагностика обзора перенесена из фиксированной области сцены в измеряемый HUD.
Осмотр не включает режим перемещения. Тело Марфы даёт явный вход «Проверить
обзор» без команд ядра и изменения маршрута.

## Проверки и происхождение кадров

- [Первый проход новой версии](player-review.md), [журнал](player-journal.md):
  100 исходных событий/PNG, L01–L03, ошибка и восстановление, План,140%,restart.
  Агент не читал код, готовые решения или старые QA и не получал подсказок команды.
- [Независимый QA](qa-final.md): 83 события основного прогона и 8 финальной
  проверки наблюдателей; [машиночитаемые результаты](qa-final.json).
- Полные нативные проходы относятся к runtime `2ce2cd9…c7c2e38`.
  Затем изменены только `game.gd` и `stage_view.gd` для осмотра наблюдателей.
  Финальные 8 кадров и все 33 набора относятся к runtime
  `b61f531c136fa30d5e67b8df83f29e2011c49b786bf5d7d7ecdcf5b2d1ee2f15`.
  Ранние кадры не выдаются за неизменяемый снимок финального APK.
- [Observer correction](observer-hotfix/README.md), [обзор через тело](observer-actions.md):
  исходный Touch-тест остался неизменным; ошибки w2/w3 устранены,14/0/30 событий.
  UI93/0/136pointer; stage34/0; input edges7/0. Тест утилиты запуска отдельно
  устранил гонку пустой `/proc/cmdline`, не изменяя правила игры.
- [Успешный GitHub run](https://github.com/pazzia/GOD-game/actions/runs/40316007540),
  [полный отчёт](../../production/ux-fixes-0.5.1/project-verification.json):
  33 обязательных набора, ноль engine/leak-строк и изменений runtime.
  Первый CI-кандидат корректно остановился на регрессии Touch и не опубликовал APK.

Это AI desktop-прогон мышью/клавиатурой на844×390 с Dummy audio.
Физический Android, touch на телефоне, человеческое понимание/удовольствие,
субъективное прослушивание и полная поздняя кампания нативно не проверены.

## Оставшиеся замечания

[PRT-01/02](player-findings.md) — две неблокирующие трудности размещения:
назначение двух мишеней раскрывается через именованное меню, а плавающая кнопка
при140% частично перекрывает альтернативную мишень. Игрок восстановился сам
и завершил уровень; недоступность нажатия перекрытой области не доказана.
Они остаются открытыми для следующей итерации и теста владельца.
