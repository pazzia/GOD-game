# Независимый UI-набор

`tests/test_ux_retest.gd`: **121 проверка, 0 ошибок**,90 событий указателя
и16 клавиатурных событий. Результат: [qa-targeted.json](qa-targeted.json).
Набор зарегистрирован как обязательный UI-gate; вместе с прежними проверками
полный registry теперь содержит33 уникальных набора.

Новый тест проверяет в настоящем SceneTree:

- обучение и явный режим размещения L01; неверное место, допустимое место, Undo;
- помещение камня поверх уже поставленного поплавка L03;
- сводку L02 до/после настоящих нажатий назначения маршрута и крепления,
  затем возврат **предыдущего крепления к якорю** через Undo;
- два использованных show-hint, отдельную помощь применения после M01,
  фактическую неудачу доставки L03 и успех после переноса камня;
- паузу, доступность без прокрутки звуковых каналов, сохранение100/120/140%,
  читаемые стили переключателей и номера03/04 на горизонтальном844×390.

Все проверяемые UI-действия используют InputEvent, а не эмиссию `pressed`.
Сложная постановка L03 подготавливается законными авторскими командами как
явная fixture; это не называется полным самостоятельным прохождением.
Первый неудачный пробный запуск теста выявил ошибки ожиданий самого QA:
модальные окна находятся вне `ui`, Undo возвращает прежний якорь вместо пустого
крепления, а `_capture_stage` останавливает игровое время. Эти ожидания исправлены,
не представлены как дефекты продукта и не были устранены ослаблением проверок.

Это headless native Control-регрессия. Отдельные растровые кадры реального
рендера нужны для художественной читаемости/попадания; физический Android,
касание пальцем и человеческое понимание этим набором не подтверждаются.
