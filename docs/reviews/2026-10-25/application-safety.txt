GOD / Almost God 0.3.0-preview — ограниченное ревью безопасности приложения
Дата UTC: 2026-10-25T09:33:35.912891+00:00
Область: статическое чтение текущего runtime, export preset и путей сохранения;
один отдельный native regression. Это не pentest, не аудит Godot/Android SDK,
не исследование сетевого трафика на телефоне и не аппаратная приёмка.

Результат: в проверенной области не обнаружены блокирующие утечки данных или
ненужные запросы опасных разрешений. Итоговый APK проверен отдельно ниже.

1. Сеть и данные. Поиск rg в core/, presentation/, services/, main.tscn,
project.godot и export_presets.cfg не обнаружил HTTPRequest/HTTPClient,
WebSocket/WebRTC/ENet/Multiplayer, сетевых адресов runtime, Analytics/Telemetry,
Firebase/Sentry/AdMob/Billing или вызовов внешнего процесса/браузера. В проекте
нет addons/ и android/ с пользовательскими SDK. Не найдены поля/сбор аккаунта,
email, телефона, координат, контактов, рекламного ID, камеры/микрофона/clipboard.
Это вывод по исходникам приложения, не доказательство отсутствия любой сетевой
возможности внутри универсального бинарника движка.

2. Разрешения. export_presets.cfg: permissions/internet=false,
permissions/vibrate=true, user_data_backup/allow=false. Вибрация используется
Input.vibrate_handheld и отключается настройкой haptics; опасного runtime prompt
для неё не требуется. minSDK29 обеспечивается tools/build_android.py через
проверяемую временную копию export template; пустое gradle_build/min_sdk само
по себе этого не доказывает. Итоговые package/version/minSDK/signature должны
подтверждаться разбором экспортированного APK. Результат итоговой проверки APK приведён ниже.

3. Локальное хранение. SaveService пишет только JSON в user://. Имя слота
допускает 1–64 символа alnum/_/-, исключая traversal. Конверт schema2, конечная
монотонная revision, SHA-256 целостности, верификация временного файла, rename
и последняя валидная backup снижают риск порчи. Это обычный checksum без
секретного ключа; он не является защитой покупок или от намеренного изменения
локального сейва. Хранятся настройки/прогресс/checkpoint, не личный профиль.
Новый preview package отделён от старой установки и её пользовательских файлов.

4. Ключи/пакетирование. Файлы .env/.keystore/.jks/.key/.p12/.pfx по именам и
tracked private signing keys в repo не обнаружены (содержимое секретов не
просматривалось). Preview key хранится вне repo; ZIP упаковщик исключает ключи,
локальные env, build/cache и symlink файлы. .gitignore больше не разрешает
исключение tools/signing/debug.keystore. old/ сохранён и исключён из runtime.

5. Остаточный риск сохранений: presentation/game.gd:_save_progress и ряд
settings callbacks не обрабатывают false от saver.write_slot. При полном диске
последняя валидная копия защищена сервисом, но игрок не получает сообщения об
отказе новой записи. Перед магазинным выпуском нужен явный UI failure/retry.
Runtime в рамках этого ревью не менялся.
