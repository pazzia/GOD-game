# Проверка доступных действий и правил

Ревизия выполнена по фактическим `presentation/game.gd`,
`core/simulation_kernel.gd` и данным всех 30 уровней. Наличие кнопки не считается
подтверждением работоспособности: критические пути проверены нативными нажатиями.

| Действие | Условие интерфейса и ядра | Проверка |
|---|---|---|
| Размещение, складывание, удаление | Подготовка либо неподписанный результат; capability/тип/доступность и нужный закон | Четыре постановки L01, отмена, invalidation, native journey |
| Перемещение наблюдателя | Только подготовка/неподписанный результат и один фиксируемый ракурс | UI phase matrix; инспекторы с несколькими ракурсами доступны для осмотра |
| Демонстрация и репетиция | Выбран допустимый ещё не активный закон | Кампания и реальные UI-пути |
| Закрепление закона | Только принятый результат, отдельная команда | L01 proof→law, отмена замены L30 |
| Включение очага | Объявленное `switchable=true`, редактируемая фаза и доступный предмет | L11 disable/enable, эффект на температуру, undo/save и off-рисунок |
| Пассивный камень и криопак | Переключателя нет; доступны их настоящие предметные действия | Отрицательные UI/core-регрессии |
| Крепление | Объявленная capability и разрешённые типы цели для всех инструментов | Mooring L02, фильтрация UI, физически показанная верёвка |
| Назначение маршрута | Только решение после закона; допустимый actor/carrier/start | Проверены все транспортные цели кампании и сложные native-пути |
| Плавание | Весь отрезочный путь находится в воде, включая промежутки между узлами | L18 canonical/alternative и отрицательные геометрические случаи |
| Запуск мира | Только `PLAN_RESOLUTION` | UI phase matrix и кампания |
| Выход из запуска | После окончания маршрутов; в ходе движения предлагается настоящий откат | Native UI-регрессия pending-route |
| Отмена | Только непустая история; интерфейс немедленно обновляет доступность | Одношаговая отмена, восстановление proof и настройки |

Устранены найденные несоответствия: неработавший `oven.disable`, маршруты и
запуск мира в неправильной фазе, пересадка фиксированного инспектора,
неподходящие цели причальной верёвки, неактивная отмена без истории и остановка
незавершённого маршрута. Ошибочные решения самой головоломки — видимый механизм,
закрытый результат, слабая опора — сохраняются как объясняемые игровые ошибки.

Дополнительно сверены имена и целевые предметы всех сюжетных карточек с actual
entities/witnesses. Исправлены фантомная лодка L13, чаша L15, неверные участники
и переходы; L18 получил настоящий отдельный водный маршрут, сохранив решения.
Это проверка согласованности реализации. Понимание правил новым человеком
и удовольствие от прохождения требуют отдельного наблюдения.
